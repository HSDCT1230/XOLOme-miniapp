### 复选框彻底修复
- **问题根因**：survey 页面使用原生 checkbox-group，checked 绑定使用 `indexOf` 在 WXML 模板中不可靠，且 `option-active` 样式太淡（12%透明度）用户难以感知
- **修复方案**：
  1. 添加 WXS 辅助模块 `helper`，封装 `isChecked`（checkbox数组查找）和 `isRadioChecked`（radio单值判断）函数
  2. 替换所有 `indexOf` / `===` 绑定为 WXS 函数调用：`helper.isChecked(answers, currentQuestion.id, item.value)`
  3. 增强 `option-active` 样式：透明度 12%→20%，边框 2rpx→4rpx，增加绿色阴影光晕 `box-shadow: 0 0 0 4rpx rgba(110,199,59,0.10)`
  4. 选中文字颜色加深 `#6ec73b`→`#4a9c2a`，字重 600→700
  5. radio 同步改用 `isRadioChecked` 保持一致性
- 涉及文件：survey.wxml, survey.wxss
- survey-form 组件（独立组件，survey 页面未使用）保持原样

## 2026-07-19 V2.1 优化（用户认知路径重构）

- **认知路径重构**：从"购买AI硬件"→"体验价值→获得首发资格→决定购买→完成交付"
