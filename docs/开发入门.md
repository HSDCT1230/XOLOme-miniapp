# XOLOme 小程序 · 开发入门（5 分钟上手）

> 按下面步骤即可在电脑上预览和改代码。

---

## 第一步：打开项目

### 方法 A：双击批处理

```
d:\cursoe_code\XOLOme-Miniapp\打开小程序项目.bat
```

### 方法 B：手动导入

1. 打开 **微信开发者工具**
2. 导入项目，目录选择：
   ```
   d:\cursoe_code\XOLOme-Miniapp\xolome-miniapp
   ```
3. AppID 留空（测试号）→ 确定 → 编译

> 必须打开 `xolome-miniapp` 这一层（含 `project.config.json`），不要打开上一级。

---

## 第二步：标准目录

```
xolome-miniapp/                 ← 开发者工具打开这里
├── miniprogram/                # 前端
│   ├── pages/                  # 主包：首页/问卷/预定/订单详情
│   ├── subpackages/            # 分包：订单列表/退款/尾款/券/我的
│   ├── components/             # 组件
│   ├── utils/                  # 配置与业务
│   └── images/
│       ├── brand/  hero/  feature/  collab/
├── cloudfunctions/             # 云函数
└── project.config.json
```

文档在仓库 `docs/`，不进入小程序上传包。

---

## 第三步：怎么改

| 想改 | 文件 |
|------|------|
| 首页 | `miniprogram/pages/index/` |
| 问卷 | `miniprogram/pages/survey/` |
| 价格/库存 | `miniprogram/utils/config.js` |
| 全局样式 | `miniprogram/app.wxss` |

保存后点 **编译**。当前 `IS_MOCK=true`，本地模拟，不会真扣钱。

---

## 常见问题

**模拟器空白？** 再点编译，或换 iPhone 机型。  
**改了没变化？** 确认打开的是 `xolome-miniapp` 目录并已保存。  
**DIY「立即体验」真机空白？** 需配置业务域名 `api.xolome.com`，见 `docs/业务域名配置.md`。开发者工具可先勾选「不校验合法域名」本地看效果。  
**准备上线？** 见 `docs/微信官方申请流程指南.md`，并把 `IS_MOCK` 改为 `false`。
