## 第一步：打开项目

### 方法 A：双击批处理

```
D:\cursoe_code\XOLOme-Miniapp\打开小程序项目.bat
```

### 方法 B：手动导入

1. 打开 **微信开发者工具**
2. 导入项目，目录选择：
   ```
   D:\cursoe_code\XOLOme-Miniapp\xolome-miniapp
   ```
3. AppID 用 `project.config.json` 中的正式号，或测试号 → 确定 → 编译

> 必须打开 `xolome-miniapp` 这一层（含 `project.config.json`），不要打开仓库根目录。

## 常见问题

**模拟器空白？** 再点编译，或换 iPhone 机型。  
**改了没变化？** 确认打开的是 `xolome-miniapp` 目录并已保存。  
**DIY「立即体验」真机空白？** 需配置业务域名 `api.xolome.com`，见 `docs/业务域名配置.md`。开发者工具可先勾选「不校验合法域名」。  
**准备上线？** 见 `docs/微信官方申请流程指南.md`、`docs/上线需求说明书.md`，并把 `IS_MOCK` 改为 `false`。
