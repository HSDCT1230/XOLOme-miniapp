## 一、产品概述

### 1.1 产品定位
XOLOme X1 是一款融合 **IP 全息视觉 + AI 陪伴 + 用户创造内容** 的新型桌面伙伴产品。该小程序承担**市场调研 + 首发预定**双重角色，限时限量 3,000 套。

### 1.2 V2.1 核心调整

#### 调整目标
从"购买一台AI硬件"转变为：
> 用户先体验 XOLOme 的独特价值 → 获得首发体验资格 → 决定购买 → 完成交付

#### 关键变更点
| 维度 | V2.0 | V2.1 |
|------|------|------|
| **用户路径** | 填问卷→付定金→补大定→付尾款 | 体验价值→填问卷→拿体验资格→决定购买 |
| **价格展示** | 显示3次分段支付 | 显示统一原价¥4,999 + 优惠¥500 + 实际¥4,499 |
| **退款文案** | 显示Day X / 宽限期 / 状态码 | 只显示"体验资格规则"和"确认购买规则" |
| **首页卖点** | IP→AI→娱乐 | IP全息伙伴→全息相册→游戏陪伴 |
| **核心认知** | AI全息伙伴 | 让喜欢的内容，成为你的桌面伙伴 |
| **后台金额** | 499+1000+3000 | **保持不变**（后端逻辑兼容） |

### 1.3 核心目标
| 指标 | 目标 | 衡量方式 |
|------|------|----------|
| 问卷收集 | ≥2,000 份 | surveys 表记录数 |
| 体验资格转化 | ≥30%（问卷→支付¥499） | orders 表 DEPOSIT_PAID 数 |
| 确认购买转化 | ≥60%（体验资格→补至¥1,499） | DEPOSIT_CONFIRMED 数 |
| 尾款完成 | ≥80%（确认购买→付¥3,000） | FINAL_PAID 数 |
| 全额退款率 | <15% | REFUNDED 数 |
| 代金券转化率 | <20% | DEPOSIT_VOUCHER + CONFIRMED_VOUCHER 数 |
| **新：第一眼认知** | 桌面伙伴占比 ≥40% | V2.1 调研数据 |
| **新：核心兴趣** | IP全息伙伴排名第1 | V2.1 调研数据 |

### 1.4 用户画像
- **年龄**：18-45岁，核心 26-35 岁
- **场景**：桌面工作学习、游戏娱乐、潮玩收藏
- **动机**：IP 全息伙伴 > 宠物家人全息 > AI 助手
- **V2.1 重点**：强化"内容创造与陪伴"认知

## 二、核心业务流程

### 2.1 用户旅程（V2.1）

```
进入小程序
  ↓
了解 XOLOme X1
  ↓
体验产品价值（首页展示）
  ↓
填写问卷
  ↓
获得¥500代金券 + 体验资格
  ↓
支付¥499锁定体验资格（60天可退）
  ↓
60天体验决策期
  ↓
确认购买：补足¥1,499
  ↓
30天确认期
  ↓
发货前支付尾款¥3,000
  ↓
完成发货
```

### 2.2 价格体系（V2.1 统一展示）

#### 对外展示
- **标准售价**：¥4,999
- **首发代金券**：¥500（完成问卷获得）
- **实际支付**：¥4,499

#### 支付分阶段（后端逻辑保持）
- 阶段1 体验资格：¥499（60天可退）
- 阶段2 确认购买：+¥1,000（30天可退，累计¥1,499）
- 阶段3 正式发货：+¥3,000（锁定订单，等待发货）

### 2.3 退款转代金券机制（**仅后端，用户端不展示细节**）

#### 体验资格 ¥499 阶段
- 60天内 → 无理由退款
- 60天后 → 提前3天通知 + 7天宽限期（每日通知）
- 宽限期结束 → ¥499转代金券（365天有效）

#### 确认购买 ¥1,499 阶段
- 30天内 → 可申请退款
- 30天后 → 提前3天通知 + 7天宽限期
- 宽限期结束 → ¥1,499转代金券（365天有效）

#### 代金券使用
- 365天内可用于 XOLOme 系列产品
- 过期未使用 → 自动作废
- 不可提现、不可转让
