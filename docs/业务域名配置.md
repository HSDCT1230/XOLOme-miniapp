# 配置业务域名 `api.xolome.com`（web-view 必做）

小程序用 `<web-view>` 打开 DIY 页 `https://api.xolome.com` 时，**必须**在微信公众平台登记业务域名，并在该域名下可访问微信下发的校验文件。未配好时真机常为空白页。

当前探测：`api.xolome.com` → `120.26.0.177`（nginx）。根路径目前返回 404，除业务域名外，还需确认 DIY H5 已部署到该地址。

---

## 你需要准备

1. **微信公众平台**管理员账号（小程序）
2. **api.xolome.com 服务器**上传权限（把校验 `.txt` 放到网站根目录）

开发者工具本地调试可勾选「不校验合法域名」；**真机预览 / 正式版无效**，仍须完成下列步骤。

---

## 步骤一：微信公众平台添加业务域名

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) → 登录小程序
2. **开发管理** → **开发设置** → **业务域名**
3. 点击 **修改** → 下载校验文件（形如 `MP_verify_xxxx.txt`）
4. 将校验文件放到服务器，保证浏览器可打开：
   ```
   https://api.xolome.com/MP_verify_xxxx.txt
   ```
   （文件名以后台下载的为准）
5. 在业务域名里填写：`api.xolome.com`（不要带 `https://`、不要带路径）
6. 保存。每月修改次数有限，一次配准即可

说明：

- 业务域名用于 `web-view`；与「request 合法域名」「downloadFile 合法域名」是不同列表，DIY 外链主要靠**业务域名**
- 域名须已备案（国内服务器）且支持 HTTPS

---

## 步骤二：服务器放置校验文件（nginx 示例）

把下载的 `MP_verify_xxxx.txt` 放到站点 **根目录**（与站点首页同级），使上述 URL 返回纯文本内容。

nginx 站点根目录示例：

```nginx
server {
  listen 443 ssl;
  server_name api.xolome.com;
  root /var/www/api.xolome.com;   # 校验文件放这里
  # ...
}
```

上传后自检：

```bash
curl -I https://api.xolome.com/MP_verify_xxxx.txt
# 期望 200，Content-Type 一般为 text/plain
```

---

## 步骤三：确认 DIY 页面可访问

业务域名通过后，`web-view` 打开的地址本身也要能打开：

```
https://api.xolome.com
```

若浏览器仍是 404，说明 H5 尚未部署到该机，需把 DIY 前端发布到此域名后再测小程序。

小程序内地址配置：`xolome-miniapp/miniprogram/utils/config.js` → `DIY_URL`。

## 静态图片 CDN（首页大图）

按[微信建议](https://developers.weixin.qq.com/community/develop/doc/00040e5a0846706e893dcc24256009)：包内只留小图标，大图用 CDN URL。

当前大图托管在 Cloudflare Pages：`https://xolome-miniapp.pages.dev/images/...`  
配置项：`config.ASSET_CDN`

真机预览前，在公众平台配置 **downloadFile 合法域名**：

1. [mp.weixin.qq.com](https://mp.weixin.qq.com) → **开发管理** → **开发设置** → **服务器域名**
2. **downloadFile 合法域名** 增加：`https://xolome-miniapp.pages.dev`
3. 保存

开发者工具本地可勾选「不校验合法域名」先看效果。

---

## 步骤四：真机验证

1. 开发者工具用正式 AppID 编译（不要用测试号测业务域名）
2. 真机预览 → 首页点「立即体验」
3. 应直接进入 DIY H5；若失败，页内会提示复制链接，并说明多半是域名未配好
