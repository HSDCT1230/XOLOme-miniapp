# 小程序需求说明书（极简）

仓库：`D:\cursoe_code\XOLOme-Miniapp` · GitHub：https://github.com/HSDCT1230/XOLOme-miniapp  
（废弃路径 `E:\Xolome微信小程序\` 勿用）

交付：微信小程序（用户端）+ Web 商家管理后台。  
不含：原生 App、分销、复杂工单系统、未列模块。

```
用户端小程序：商品预定｜尾款履约｜问卷调研｜线上体验｜个人中心
        │
        ▼ 接口
商家 Web 后台：商品订单｜资金发货｜问卷数据｜体验配置｜基础运维
```

---

## 一、用户端（微信小程序）

须对接后台配置与订单 / 支付 / 问卷等接口。

### 1. 商品预定

| 功能 | 说明 |
|------|------|
| 商品展示 | 展示已上架可预定商品 |
| 规格选择 | 选择规格后进入支付 |
| 定金支付 | 微信支付定金 |
| 生成预定单 | 支付成功后订单可查 |

**验收**：可选规格 → 付定金 → 订单可见；取消支付无已付单。

### 2. 尾款履约

| 功能 | 说明 |
|------|------|
| 尾款到期提醒 | 按后台配置期限提醒 |
| 在线补缴 | 支付尾款 |
| 物流跟踪 | 后台录入后可见单号/状态 |
| 确认收货 | 确认后订单完结 |

**验收**：可提醒、可付尾款、可查物流、确认收货状态正确。

### 3. 问卷调研

| 功能 | 说明 |
|------|------|
| 填写提交 | 按后台已发布问卷提交 |
| 历史记录 | 查看本人历史提交 |

**验收**：可提交；历史可查；数据可在后台导出。

### 4. 线上功能体验

| 功能 | 说明 |
|------|------|
| 试用入口 | 进入后台已开启的体验功能 |
| 体验数据留存 | 试用数据可供后台查看/统计 |

**验收**：后台关闭则不可用；开启可进入；有留存记录。

### 5. 个人中心

| 功能 | 说明 |
|------|------|
| 收货地址 | 增删改查 |
| 全部订单 | 订单总览与详情入口 |
| 客服入口 | 按后台配置打开 |

**验收**：地址可用；订单与支付状态一致；客服入口可用。

---

## 二、商家管理后台（Web）

须支撑小程序预定、支付、问卷、体验、履约。

### 1. 商品订单管控

| 功能 | 说明 |
|------|------|
| 商品上下架 | 控制小程序是否可预定 |
| 预定规则 | 定金比例、尾款支付期限 |
| 订单状态流转 | 全生命周期查看与管理 |

**验收**：下架后不可新预定；规则对后续订单生效；状态与小程序一致。

### 2. 资金发货管理

| 功能 | 说明 |
|------|------|
| 定金/尾款对账 | 按订单查支付，可与商户核对 |
| 发货录入 | 录入发货与物流单号 |
| 物流同步 | 同步至用户端可查 |

**验收**：已付可对账；录入后用户可见物流；发货状态正确。

### 3. 问卷数据管理

| 功能 | 说明 |
|------|------|
| 创建发布 | 创建并发布到小程序 |
| 统计导出 | 回收数据统计与导出 |

**验收**：发布后可填；停用后不可新填；导出字段完整。

### 4. 体验功能配置

| 功能 | 说明 |
|------|------|
| 权限 | 控制可体验范围 |
| 时长 | 可用时长 |
| 内容开关 | 开关体验内容 |

**验收**：配置即时影响小程序；有基本变更记录即可。

### 5. 基础运维

| 功能 | 说明 |
|------|------|
| 用户管理 | 查看用户基本信息 |
| 客服配置 | 配置小程序客服入口 |
| 经营数据总览 | 订单/收款/问卷等汇总 |

**验收**：可查用户；客服入口正确；总览与明细大致一致。
