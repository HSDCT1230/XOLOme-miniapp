# DIY 功能与流程梳理

> 对齐 `TAGS.md` / `aigc-templates.json` / 飞书提示词 · `2026-08-10n`

## 产出结构（统一）

每个入口：**1 张图生图**（白底 + 单影；风格模板做风格化，通栏真人不风格化）**× 3 条图生视频动作**（继承首帧光影）。

## 主路径

```
01 选入口（通栏真人 or 风格模板 01–19）
02 上传（按模板 input：正脸自拍 / 自拍半身 / 全身 / 宠物照…）
03 首帧 ← 步骤 A 图生图
04 玩法 ← 步骤 B 图生视频
05 详情 → 06 投放设备
```

## 关键模板逻辑

| 入口 | 上传 | 步骤 A |
|------|------|--------|
| 真人全息动态 | 真人照 | 无风格化，一键变成动态 |
| 自拍盲盒 | 自拍可半身 | 补全身 + 手持手机潮玩盲盒娃（封面：卫衣牛仔） |

| 其它风格 | 见 TAGS | 风格化首帧 |
