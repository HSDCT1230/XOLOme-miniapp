# DIY 功能与流程梳理（v2）

> 对齐 `hub-taxonomy.mjs` / `TAGS.md` / `aigc-templates.json` · `2026-08-11c`

## 产出结构（统一）

每个入口：**1 张图生图**（白底 + 单影；复刻不风格化，变身风格化）**× 3 条图生视频动作**（继承首帧光影）。

## 主路径

```
01 一级：选大类（真人 / 宠物 / 玩具全息动态）
01a/b/c 二级：瀑布流（00 复刻 + 变身风格…）
02 三级：上传（按模板 input）
03 首帧 ← 步骤 A 图生图
04 玩法 ← 步骤 B 图生视频
05 详情 → 06 投放设备
```

## 关键模板逻辑

| 类型 | 上传 | 步骤 A |
|------|------|--------|
| 复刻（各大口 00） | 对应类型清晰照片 | 无风格化，白底单影还原 |
| 变身自拍盲盒 | 自拍可半身 | 补全身 + 潮玩盲盒娃 |
| 变身bjd学院风证件照 | 正脸自拍 | 只换脸；身体=学院风BJD模板 |
| 其它变身 | 见 TAGS | 风格化首帧 |
