## bjd学院风证件照 · 产品规则

1. 用户**只上传正脸自拍**（不必全身）  
2. 步骤 A：**只保留用户脸部身份**，丢弃用户身体/服装/背景  
3. **身体与校服完全采用模板参考图**（浅灰西装外套、白衬衫、深灰百褶裙、乐福鞋、站立证件照姿态）  
4. 输出：与参考图同身型的学院风 BJD 证件照（`tpl-22-bjd-school-id.png`）
