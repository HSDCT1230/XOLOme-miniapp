# DIY 首页标签体系（v2.3）

> 源真：`hub-taxonomy.mjs` + `aigc-templates.json`

## 信息架构

```
一级首页：三大类入口（真人 / 宠物 / 玩具）—— 无「复刻」标签
         └─ 点击进入二级
二级页：首位突出「复刻」+ 下方变身风格瀑布流
三级：上传 → 首帧 → 玩法 → 详情 → 设备
```

## 交互

| 操作 | 去向 |
|------|------|
| 首页大类卡 / 选择风格 | 对应二级页（可滚动） |
| 二级「复刻」卡 / 开始复刻 | 上传页 |
| 二级变身模板卡 | 上传页 |
| ‹ 首页 | 首页手机预览 |
