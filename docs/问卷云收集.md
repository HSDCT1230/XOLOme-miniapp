# 问卷结果真实入库（云开发）

当前默认 `IS_MOCK = true`，问卷只写在手机本地，**后台看不到**。按下面做，提交会进入微信云开发数据库 `surveys` 集合。

## 一、你要准备的

1. 小程序已登录你有权限的 AppID（管理员/开发者）
2. 开发者工具打开目录：`D:\cursoe_code\XOLOme-Miniapp\xolome-miniapp`（含 `project.config.json`；仓库 https://github.com/HSDCT1230/XOLOme-miniapp）

## 二、开通并部署（约 10 分钟）

1. 开发者工具顶部点 **云开发** → 开通（按提示创建环境）
2. 记下 **环境 ID**（形如 `xolome-xxxxx`）
3. 填到 `miniprogram/utils/config.js`：
   ```js
   const IS_MOCK = false;
   cloudEnv: '你的环境ID',  // 也可留空，使用工具当前默认环境
   ```
4. 在云开发控制台 → **数据库** → 新建集合：`surveys`  
   权限建议先用「仅管理端可读写 / 创建者可读写」；云函数用服务端权限写入，不受客户端规则限制。
5. 右键 `cloudfunctions/survey` → **上传并部署：云端安装依赖**
6. 编译小程序 → 填一份问卷提交  
7. 云开发 → **数据库** → `surveys` → 应能看到新记录（含 `wishIp`、`ipShellPremium`、`digitalBudget`、`couponCode` 等字段）

## 三、后台怎么看 / 导出

| 方式 | 操作 |
|------|------|
| 控制台查看 | 云开发 → 数据库 → `surveys` |
| 导出 Excel | 集合右上角导出 / 或用云开发「导出」 |
| 筛选 | 可按 `participation`、`priceRange`、`gender`、`ipShellPremium`、`channels` 等字段筛选 |

每条记录包含：

- `data`：原始题号答案  
- 展开字段：`age`、`gender`、`digitalBudget`、`purchaseHistory`、`wishIp`、`ipShellPremium`、`ipMerchPayCap`、`priceRange`…  
- `openid` / `userId`、`couponCode`、`createdAt`

同一微信用户重复提交会返回**原券码**，不重复写库刷券。

## 四、常见失败

| 现象 | 处理 |
|------|------|
| 提交失败：云函数不存在 | 未部署 `survey`，重新上传部署 |
| 找不到环境 | `cloudEnv` 填错，或未开通云开发 |
| 数据库权限错误 | 用云函数写入；检查集合名是否为 `surveys` |
| 仍提示「本地模拟」 | `IS_MOCK` 还是 `true`，改为 `false` 后重新编译 |

## 五、和 Mock 的切换

| `IS_MOCK` | 问卷去向 |
|-----------|----------|
| `true` | 本机 Storage，方便 UI 调试 |
| `false` | 云数据库 `surveys`，可后台收集 |

订单/支付等其他模块若仍走 Mock，可后续再逐个切云函数；**问卷已可单独先上真实收集**。
