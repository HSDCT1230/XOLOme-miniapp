3.2 总状态机

stateDiagram-v2
  [*] --> PENDING_DEPOSIT: 创建订单
  PENDING_DEPOSIT --> DEPOSIT_PAID: 付499成功
  PENDING_DEPOSIT --> CANCELLED: 取消未支付
  DEPOSIT_PAID --> DEPOSIT_CONFIRMED: 补款1000成功
  DEPOSIT_PAID --> REFUNDED: 窗口或宽限内退款
  DEPOSIT_PAID --> DEPOSIT_GRACE: 超60天由调度触发
  DEPOSIT_GRACE --> DEPOSIT_CONFIRMED: 宽限内仍可补款
  DEPOSIT_GRACE --> REFUNDED: 宽限内退款
  DEPOSIT_GRACE --> DEPOSIT_VOUCHER: 宽限到期转499券
  DEPOSIT_CONFIRMED --> LOCKED: 确认锁定
  DEPOSIT_CONFIRMED --> REFUNDED: 窗口或宽限内退累计1499
  DEPOSIT_CONFIRMED --> CONFIRMED_GRACE: 超30天由调度触发
  CONFIRMED_GRACE --> LOCKED: 宽限内可锁定
  CONFIRMED_GRACE --> REFUNDED: 宽限内退累计1499
  CONFIRMED_GRACE --> CONFIRMED_VOUCHER: 宽限到期转1499券
  LOCKED --> FINAL_PAID: 付尾款3000
  FINAL_PAID --> SHIPPED: 管理员发货
  DEPOSIT_VOUCHER --> VOUCHER_USED: 券用于新单
  CONFIRMED_VOUCHER --> VOUCHER_USED: 券用于新单
  DEPOSIT_VOUCHER --> EXPIRED: 券过期
  CONFIRMED_VOUCHER --> EXPIRED: 券过期

3.3 付款流程（499）

flowchart TD
  A["预定页勾选协议"] --> B["order.create"]
  B --> C{"库存与一人一有效单"}
  C -->|"失败"| Z1["提示售罄或已有订单"]
  C -->|"成功"| D["payment.prepay DEPOSIT"]
  D --> E["服务端核定 totalFee = max(0, 49900 - voucherAmount)"]
  E --> F["wx.requestPayment"]
  F -->|"取消或失败"| G["保持 PENDING_DEPOSIT 可重试"]
  F -->|"支付成功"| H["payment.callback"]
  H --> I{"幂等: transactionId 未处理?"}
  I -->|"已处理"| J["直接返回成功"]
  I -->|"首次"| K{"状态仍 PENDING_DEPOSIT?"}
  K -->|"否"| Z2["记异常流水并人工核对"]
  K -->|"是"| L["订单变为 DEPOSIT_PAID"]
  L --> M["写 refundDeadline +60d 与 graceDeadline +67d"]
  M --> N["写 payments 流水含 outTradeNo"]
  N --> O["扣减库存占位"]
  O --> P["通知体验资格支付成功"]
  P --> Q["前端 order.get 刷新 禁止本地写已付"]

3.4 补款流程（1000）

flowchart TD
  A["订单详情确认购买入口"] --> B{"状态为 DEPOSIT_PAID 或 DEPOSIT_GRACE?"}
  B -->|"否"| Z1["无入口或拒绝"]
  B -->|"是"| C["payment.prepay CONFIRMATION"]
  C --> D["服务端核定 totalFee=100000"]
  D --> E["wx.requestPayment"]
  E -->|"取消"| F["保持原状态可重试"]
  E -->|"成功"| G["payment.callback"]
  G --> H{"幂等且状态仍允许补款"}
  H --> I["订单变为 DEPOSIT_CONFIRMED"]
  I --> J["重置 refundDeadline +30d 与 graceDeadline +37d"]
  J --> K["写 CONFIRMATION 支付流水"]
  K --> L["展示确认购买规则与退款入口"]

3.5 尾款流程（3000）

flowchart TD

  J -->|"是"| K["订单变为 FINAL_PAID"]
  K --> L["写 FINAL 支付流水"]
  L --> M["通知尾款支付成功待发货"]
  M --> N["管理员 order.ship 变为 SHIPPED"]

3.6 退款流程

flowchart TD
  A["用户申请退款"] --> B["refund.apply 仅传 orderId"]
  B --> C{"归属与状态白名单且 now 小于 graceDeadline 且无进行中退款单"}
  C -->|"否"| Z1["拒绝并说明原因"]
  C -->|"是"| D{"当前阶段"}
  D -->|"体验资格"| E["退 DEPOSIT 499"]
  D -->|"确认购买"| F["退 DEPOSIT 与 CONFIRMATION 累计 1499 逐笔"]
  E --> G["cloudPay.refund 写 refunds PROCESSING"]
  F --> G
  G --> H["refund.callback 逐笔 SUCCESS"]
  H --> I{"该单全部退款是否成功"}
  I -->|"否"| J["保持处理中"]
  I -->|"是"| K["订单变为 REFUNDED"]
  K --> L["回补库存"]
  L --> M["发退款成功通知"]
