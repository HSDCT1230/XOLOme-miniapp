## 一、环境准备

### 1.1 安装微信开发者工具

```
1. 下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选择 macOS 稳定版
3. 安装后打开
```

### 1.2 导入项目

```
1. 打开微信开发者工具
2. 点击「导入项目」
3. 目录选择：xolome-miniapp/
4. AppID：留空（使用测试号模式）
5. 项目名称：XOLOme X1
6. 点击「确定」
7. 等待编译完成
```

### 1.3 模拟器设置

```
工具栏 → 模拟器 → 选择 iPhone 14 Pro
（如果模拟器空白，点击「编译」按钮）
```

### 验证 6：时间加速测试（核心！）⏩

**这是模拟验证的核心功能——测试宽限期和代金券流转。**

#### 测试意向金 60 天到期

```
1. 创建一个新订单（不要补足大定）
2. 在开发者工具「控制台」中输入：

   const MOCK = require('../../utils/mock-data');
   const orders = MOCK.getMyOrders();
   const order = orders[0];
   console.log('订单ID:', order.id);
   console.log('当前状态:', order.status);

   // 模拟67天后（60天+7天宽限期）
   MOCK.fastForward(order.id, 67);
   MOCK.runScheduler();
   console.log('模拟完成！请刷新页面查看');
```

**预期结果**：
- 刷新页面前状态 DEPOSIT_PAID
- 执行 fastForward(67天) + runScheduler
- 刷新后订单状态变为 DEPOSIT_VOUCHER
- 显示「¥499 已转为代金券」
- 代金券有效期倒计时约365天

#### 测试大定 30+7 天到期

```
1. 创建一个已补足大定的订单
2. 控制台执行：

   MOCK.fastForward(order.id, 37); // 30天犹豫期 + 7天宽限期
   MOCK.runScheduler();
```

**预期结果**：订单状态变为 CONFIRMED_VOUCHER，¥1,499 转代金券

## 三、控制台测试命令速查

在开发者工具「控制台」中可直接运行：

```javascript
const MOCK = require('../../utils/mock-data');
const CONFIG = require('../../utils/config');
const STATE = require('../../utils/state-machine');

// ---- 查看数据 ----
MOCK.getMyOrders()           // 查看我的订单
MOCK.getMySurvey()           // 查看我的问卷
MOCK.getMyVouchers()         // 查看我的代金券
MOCK.getStockRemaining()     // 查看剩余库存

// ---- 快速操作 ----
const orders = MOCK.getMyOrders();
const o = orders[0];

// 查看订单详情
MOCK.getOrder(o.id)

// 补足大定
MOCK.mockPay(o.id, 100000, 'CONFIRMATION')

// 退全款
MOCK.applyRefund(o.id, '不满意')

// ---- 时间加速 ----
MOCK.fastForward(o.id, 67)      // 向前推67天
MOCK.runScheduler()              // 执行定时流转
// 然后刷新页面查看结果

// ---- 重置所有测试数据 ----
MOCK.resetAllData()
```
